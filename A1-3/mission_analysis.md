# A1-3 미션 분석 및 현황

## 미션 핵심 요약

AI 코딩 도구를 활용해 Vanilla HTML/CSS/JavaScript 프론트엔드와 Python 기반 Vercel Serverless Function을 갖춘 AI 웹 서비스를 만들고, 공개 URL에서 동작을 확인해 제출 패키지 5종을 준비한다.

## 필수 산출물 현황

| 산출물 | 현재 상태 | 남은 확인 |
| --- | --- | --- |
| 배포 웹 서비스 | Vercel 배포 완료: https://codyssey-a1.vercel.app/ | 배포 환경의 실제 AI 요청·응답 확인 필요 |
| GitHub 저장소 | `hongbinwee/codyssey-A1`의 `A1-3/`에 코드와 커밋 이력이 있음 | 문서 변경분은 검토 후 push 필요 |
| README.md | 로컬 문서에 서비스·기술·실행·환경 변수·주소 설명 반영 | 원격 저장소에 반영하고 링크 재확인 |
| 서비스 기획서 | `docs/service_plan.md`에 목적·대상·페이지·AI 입력/출력/실패 처리 정리 | 현재 상태와 사용자 결정 최종 검토 |

## 기능 요구사항 현황

| 요구사항 | 현재 상태 | 근거 또는 남은 작업 |
| --- | --- | --- |
| 서비스 목적·타겟 정의 | 문서화됨 | `docs/service_plan.md` |
| 3개 이상 페이지/섹션과 메뉴 이동 | 구현·로컬 검증됨 | `index.html`, `diagnosis.html`, `contact.html`; 홈 앵커 포함 |
| Vanilla HTML/CSS/JavaScript | 구현됨 | 프론트 구조와 의존성 확인 |
| 반응형 화면 | 1440px·768px·390px 캡처 보유 | 제출 전 배포 URL에서 다시 확인 |
| 사용자 입력 → `fetch` → Python API → 결과 | mock 응답으로 통합 검증됨 | 실제 배포 AI 응답은 아직 확인하지 않음 |
| 실패 안내 | 빈 입력·API 오류·지연 처리 구현 | mock/브라우저 테스트 기록 확인 |
| Python Vercel Function | 구현되어 배포 패키지에 포함 | 실제 배포 함수의 성공·오류 경로 재검증 필요 |
| `requirements.txt` | 존재 | 외부 패키지 없이 표준 라이브러리 사용 |
| Vercel 배포 | 사이트 배포 확인됨 | 전체 기능 배포 검증은 미완료 |
| README·서비스 기획서 | 로컬 수정 반영 | GitHub push 후 원격 파일 재확인 |
| AI 기능 증빙 | mock 결과 캡처만 있음 | 실제 AI 응답 캡처 추가 필요 |
| AI 도구 사용 증빙 | 사용 과정 요약 기록 있음 | 제출용 대화 로그 또는 스크린샷 세트 추가 필요 |

## 학습 목표 기록

`docs/learning_log.md`에 HTML·CSS·JavaScript 역할, 입력부터 응답 표시까지의 흐름, Python Function, 환경 변수, 로컬·배포 차이, AI 코드 오류 수정 사례를 기록했다. 기록은 설명 초안이므로 제출 전 학습자가 이해한 내용인지 확인하고 자신의 말로 보완한다.

## AI 분석 결과 검토 기준

AI가 작성한 문서와 결과는 미션 원문·실제 코드와 대조한다.

- 원문에 없는 조건을 추가하지 않았는가?
- 필수 산출물이나 요구사항을 빠뜨리지 않았는가?
- 기능 요구사항을 잘못 해석하지 않았는가?
- 모호한 사항을 확인 없이 확정 사실처럼 썼는가?
- 어려운 개념을 학습자 수준에 맞게 설명했는가?
- 존재하지 않는 참고 링크나 검증 결과를 만들지 않았는가?

## 제출 전 남은 작업

1. 문서 변경분을 검토해 `hongbinwee/codyssey-A1`의 `A1-3/`에 반영한다.
2. 배포 환경에서 실제 AI 진단을 최소 1회 실행하고 결과·오류 동작을 확인한다. 호출 비용이 발생할 수 있으므로 불필요한 재시도는 하지 않는다.
3. 실제 AI 결과 화면과 AI 코딩 도구 대화 로그 또는 스크린샷 세트를 증빙 폴더에 추가한다.
4. 배포 URL에서 데스크톱·모바일, 메뉴 이동, 진단, 오류 안내를 다시 점검한다.
5. 저장소·문서·스크린샷에 비밀 값이 없는지 확인한다. 이전에 대화에 공유된 키는 제출 전 폐기·재발급하는 편이 안전하다.
6. 학습 기록을 본인이 설명할 수 있는지 확인하고, 제출 대상 파일만 남긴다.

## 미션 제출에 포함할 파일

필수 범위는 웹 서비스 코드, README, 서비스 기획서, 화면 증빙, AI 도구 사용 증빙이다. `AGENTS.md`, `WORKFLOW.md`, 내부 PRD/아키텍처 초안, 임시 검증 스크립트와 디버그 캡처는 필수 제출물이 아니므로 별도로 선별한다.
