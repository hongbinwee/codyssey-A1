# A1-3 제출 전 점검표

## 필수 산출물

- [x] Vercel에 웹사이트가 배포되어 있고 공개 URL이 있다: https://codyssey-a1.vercel.app/
- [x] GitHub 저장소에 A1-3 코드가 있으며 프론트엔드와 `api/`가 구분되어 있다.
- [x] README에 서비스 소개, 기술 스택, 실행 방법, 배포 URL, 환경 변수 설정 방법이 있다.
- [x] 서비스 기획서에 목적, 타겟, 페이지 구성, AI 입력·출력·실패 처리가 정리되어 있다.
- [x] 데스크톱·모바일 화면 캡처가 있다.
- [ ] 배포 환경에서 실제 AI 요청이 성공하고 결과가 표시되는 것을 확인했다.
- [ ] 실제 AI 기능 동작 장면을 캡처했다. 현재 결과 화면 캡처는 mock이다.
- [ ] AI 코딩 도구 사용 과정의 대화 로그 또는 스크린샷 세트를 준비했다. 요약 기록만으로는 제출 증빙을 대체하지 않는다.

## 구현·검증

- [x] 최소 3개 이상의 페이지 또는 섹션과 메뉴 이동이 있다.
- [x] 프론트엔드는 순수 HTML/CSS/JavaScript로 구현했다.
- [x] Python Serverless Function을 `api/`에 구현하고 `requirements.txt`를 포함했다.
- [x] 사용자 입력을 `fetch('/api/diagnose')`로 보내고 화면에 결과를 표시한다. 로컬 mock 흐름으로 확인했다.
- [x] 빈 입력과 API 오류 안내를 테스트했다. 타임아웃 안내는 구현 상태와 검증 범위를 구분해 기록했다.
- [x] 1440px·768px·390px 화면을 확인했다.
- [ ] 배포 URL에서 네비게이션·반응형·진단 성공·실패 흐름을 최종 확인했다.
- [x] 로컬 테스트 기록: 백엔드 12개, HTTP 통합 10개, Playwright 33개 통과.
