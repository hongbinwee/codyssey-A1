# A1-3 증빙 자료

이 폴더의 화면 자료는 구현·검증 결과를 보여준다. 디자인 참고 이미지와 실제 서비스 화면 캡처는 구분하며, 공유된 예시 와이어프레임은 미션 제출 필수 자료가 아니다.

## 현재 보유한 화면 자료

- 데스크톱 홈: `desktop-1440-home.png`
- 데스크톱 상담: `desktop-1440-contact.png`
- 모바일 홈: `mobile-390-home.png`
- 태블릿 홈: `tablet-768-home.png`
- 다크 모드 홈: `desktop-1440-home-dark.png`
- 진단 mock 결과 및 오류 상태: `desktop-1440-diagnosis-result.png`, `desktop-1440-diagnosis-error.png`

## 검증 상태와 남은 증빙

- mock 진단 결과 캡처는 `AXG_MOCK_AI=1`로 생성했다. 실제 AI 응답 장면으로 제출하지 않는다.
- 로컬 mock 백엔드 테스트 12개, HTTP 통합 테스트 10개, Playwright 검증 33개가 기록되어 있다.
- 웹사이트는 Vercel에 배포되어 있다: https://codyssey-a1.vercel.app/
- 배포 환경에서 실제 AI 요청이 성공하고 결과가 표시되는 장면은 아직 확인·캡처하지 않았다. 이 검증이 끝나면 mock 화면과 별도 파일로 저장한다.
- AI 코딩 도구 사용 과정은 `docs/ai_usage_log.md`에 요약했다. 미션에서 요구하는 대화 로그 또는 화면 캡처 세트는 아직 추가해야 한다.

## 제출 전 보안 확인

- API 키, 환경 변수의 실제 값, 세션 토큰을 캡처에 포함하지 않는다.
- 예시 입력만 사용하고 실제 고객 정보나 진단 자료는 사용하지 않는다.
- 키 유출이 의심되면 해당 키를 폐기·재발급하고, 저장소 이력 정리와 재배포 후 폐기 키가 무효인지 확인한다.
