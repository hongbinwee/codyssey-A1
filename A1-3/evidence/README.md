# A1-3 증빙 자료 폴더

이 폴더에는 최종 제출에 필요한 스크린샷과 AI 코딩 도구 사용 증빙을 저장한다.

## 필요한 증빙

- 데스크톱 화면: `desktop-1440-home.png`
- 모바일 화면: `mobile-390-home.png`
- 태블릿 화면: `tablet-768-home.png`
- 다크 모드: `desktop-1440-home-dark.png`
- 진단 결과와 오류 화면: `desktop-1440-diagnosis-result.png`, `desktop-1440-diagnosis-error.png`

## 증빙 상태

- 진단 결과 캡처는 `AXG_MOCK_AI=1`로 만든 mock 응답이다. 실제 AI 응답 증빙으로 사용하지 않는다.
- mock 모드 백엔드 테스트 12개와 HTTP 통합 테스트 10개가 통과했다.
- 실제 게이트웨이 호출은 로컬 실행 환경의 외부 443 연결이 차단되어 확인하지 못했다. 배포 환경에서 `AI_API_KEY` 설정 후 정상 응답 캡처를 추가해야 한다.
- AI 코딩 도구 사용 과정은 `docs/ai_usage_log.md`에 요약되어 있다. 제출용 대화 화면 캡처는 별도로 추가해야 한다.

## 보안 주의

- API 키, 환경 변수 값, 비밀 토큰이 보이는 이미지는 제출하지 않는다.
- 키 유출이 의심되면 키를 즉시 폐기·재발급하고, 노출된 커밋 이력을 정리한 뒤 재배포한다.
