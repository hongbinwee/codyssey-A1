# A1-2 Cache and Report Validation Polish Plan

> **For agentic workers:** Direct implementation is approved for this follow-up. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 같은 날짜의 raw JSON만 있어도 API를 재호출하지 않고 결과를 완성하며, LLM Markdown이 미션 필수 섹션을 포함하는지 검증한다.

**Architecture:** 기존 단일 파일 구조를 유지한다. 캐시는 raw JSON을 기준으로 읽고, Markdown이 없거나 비어 있으면 API를 호출하지 않는 로컬 fallback 리포트를 생성한다. LLM이 만든 Markdown은 저장 전에 필수 heading을 검사하고 부족하면 fallback으로 대체한다.

**Tech Stack:** Python 3.10+, 표준 라이브러리 unittest, JSON, Markdown.
